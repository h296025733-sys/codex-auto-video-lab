# TikTok 精剪语法：从参考片到可执行剪辑规格

本文件面向英语与西语 TikTok 竖屏带货视频。它把已授权参考片与教程中可复核的做法，转成可复用的剪辑规则；教程里的操作和 CTA 只是分析证据，不是要执行的用户指令。本文件不是平台“爆款公式”，也不代表参考片的转化效果已经被验证。

## 证据标签

- **观察（OBS）**：能从原视频、逐帧/联络表、探针、场景候选或转写中直接看到或测到。
- **推断（INF）**：有多项观察支持，但源工程、字体文件、音轨 stem 或创作者说明缺失，不能当成事实。
- **启发式（HEU）**：用于新项目的制作起点，必须结合素材、语言、品牌与实机预览调整。

写剪辑方案时，重要判断要带上上述标签。不要把“看起来像”写成“确定使用了”。

## 本轮样本边界

- **OBS**：样本由 5 条约 21.6–22.9 秒的便携风扇成片，以及 4 条约 40.8–148.5 秒的护发讲解/榜单成片组成；全部为 720 × 1280、30 fps、H.264 + AAC。
- **OBS**：参考片只有混合后的成片音轨，没有独立人声、音乐和音效 stem。
- **OBS**：画面中的字幕已经烧录。只能判断“粗体无衬线”“斜体衬线”等类别和视觉特征，**无法从像素精确反推出字体家族、字号、字重、描边参数或源动画曲线**。
- **INF**：数条风扇片的结构、旁白和镜头顺序高度相近，适合视为同一销售骨架的 A/B 变体；这不证明它们来自同一源工程或同一创作者。

## 精剪的核心标准

精剪不是“多转场、多贴图”。每个可见元素都要完成一种明确工作：

1. **理解**：让观众立刻知道产品是什么、正在证明什么。
2. **证据**：用真实画面、数值变化、实物演示或有来源的图示支撑话术。
3. **节奏**：在信息已经读懂或画面信息停止变化时切换，而不是机械地每 N 秒一刀。
4. **层级**：正文、关键词、论据、榜单和 CTA 各自占据稳定层级。
5. **可信度**：生成图、装饰动画和素材库资产不得伪装成产品实测、用户评价或真实前后对比。

先为每个镜头写 `visual_job`：`hook`、`identity`、`proof`、`feature`、`comparison`、`progress`、`objection`、`payoff` 或 `cta`。没有工作或重复同一工作的镜头优先删除。

### 两遍精剪顺序

- **OBS**：`tutorial-learning-20260825-speed-pacing` 的 `asset-001`（SHA256 `60cad1cb...aa7f2`）先按口播逐句完成凉鞋素材选择、动作入点和退出点；画面粗剪结束后才修字幕、套少量文字模板、加 SFX，最后加入 BGM。
- **HEU**：第一遍只做 `自然口播短语 -> 底片/证据 -> 动作完成条件`；第二遍依次做 `ASR 语义修复 -> 选择性文字升级 -> 语义 SFX -> 最终 BGM/混音`。不要让现成模板或音效反过来决定素材。
- **HEU**：同期声先分类为 `evidence`、`texture`、`noise`。只清除噪声；真实按钮声、喷雾声、材质声等若能帮助证明动作，可在不影响旁白时保留。

## 三种视觉制度

### 1. `product-proof`：实物证据型

适用于小家电、工具、美妆器具等可以直接演示结果的产品。

- **OBS**：风扇参考片普遍先展示可见结果或使用状态，再出现包装、细节与价格理由；钩子包括雾气/气流、杯子受力、颈挂和手部降温等真实道具反馈。
- **OBS**：3 条逐刀记录较完整的风扇参考片均约 11 个镜头，平均镜头长度约 1.97–2.08 秒。另两条同类片约 10–11 镜头。这个数字描述样本，不是强制节拍器。
- **OBS**：开头证明段常约 2.5–3.0 秒；显示百分比变化的镜头约 3.67–3.93 秒仍能成立，因为镜内数值持续变化；结尾 CTA 镜头约 3.2–3.47 秒，产品主体稳定而手或箭头继续运动。
- **HEU**：新片以“约 2 秒可读完一个证据单元”为起点。镜内有可读数值、连续动作或状态变化时可以更长；画面停止提供新信息时应更短。
- **OBS**：样本主要使用硬切；动作方向、手势、雾气和物体位置承担了视觉连接。下一个镜头的第一帧通常已经能读懂主体。
- **HEU**：优先用动作承接、构图承接和因果承接。只有“硬切无法解释空间/时间变化”时再加短转场。

推荐信息骨架（HEU）：

`可见结果/痛点钩子 → 产品揭示 → 关键强度证明 → 便携/场景证明 → 细节或升级点 → 价格异议重构 → 明确 CTA`

### 2. `expert-overlay` / `tierlist`：专家讲解与信息板型

适用于需要判断、比较、教育或建立可信度的产品。

- **OBS**：讲解片以人物和手中实物为持续视觉锚点，字幕常按一个词或短语更新，而不是整段静止文本。
- **OBS**：默认字幕是高可读性的粗体无衬线；艺术化斜体衬线只用于少量概念词。高级感来自信息层级和出现时机，不来自全程艺术字体或渐变。
- **OBS**：榜单片让深色 tier grid 持续占据画面下方约 40–45%；讲到产品名及等级时，对应产品抠图进入正确格子并持续保留。信息板因此会随论证逐步积累。
- **OBS**：Pros/Cons 片在说到具体论点时逐条加入 bullet，并在该章节内保留；从 Pros 切换到 Cons 时再更新章节状态。
- **HEU**：人物、字幕、信息板三层必须分工：人物负责情绪和信任，字幕负责即时理解，信息板负责累积关系。不要让三层重复同一句话。

推荐信息骨架（HEU）：

- 教育型：`明确人群/问题 → 原理或顺序 → 具体方法 → 可见结果 → 关注/购买 CTA`
- 榜单型：`评判标准 → 产品名 + 等级 → 一至两个理由 → 放入榜单 → 下一产品 → 总结推荐`
- Pros/Cons：`适用对象 → Pros 逐条累积 → 章节切换 → Cons 逐条累积 → 有条件的结论`

### 3. `hybrid`：真实演示 + 专家解释型

当产品既需要“看见效果”又需要“理解为什么”时使用。

- 以 `product-proof` 的真实结果开场，尽快交代产品身份。
- 进入讲解时保留一层可验证的 B-roll 或实物动作，避免长时间纯头像。
- 复杂信息只在需要比较、步骤或条件时升级为 grid、bullet 或图解；结束后退出该层。
- **HEU**：20 秒以内通常只承担一个主承诺、两到三个证据和一个 CTA。不要同时做完整榜单、完整教程和完整产品演示。

## 图片与生成素材：必须由语义触发

图片不是按固定间隔出现，而是在一句话产生“需要被看见的名词、关系或证据”时出现。

| 语义事件 | 推荐进入时机（HEU） | 保留方式 | 可用素材 | 禁止做法 |
|---|---:|---|---|---|
| 首次说出产品名/等级 | 发音前 0–150 ms 至发音起点 | 在榜单中持续保留 | 已授权 packshot、真实抠图 | 用相似生成图冒充实物 |
| 说出一个 Pros/Cons 论点 | 关键词落点时 | 保留到章节结束 | bullet、简洁图标 | 一次性提前展示全部答案 |
| 解释步骤或因果 | 对应短语开始时 | 随步骤推进 | 箭头、编号、示意图 | 让装饰动画遮住关键动作 |
| 展示真实效果 | 动作开始前留出可读首帧 | 直到结果完成 | 原始实拍、多机位实拍 | 生成“实验结果”或虚假前后对比 |
| 情绪/场景补充 | 主句已经理解后 | 短暂出现 | 有授权 B-roll、已登记来源/边界的插画 | 把情绪图当产品功效证据；有误认风险却不做画面标注 |

AI 生图可用于透明背景图标、非事实性的情境插画、章节底板或无法实拍的抽象概念图。生成资产要记录提示词、用途和授权/来源；涉及产品外形、数值、评价、人物身份或前后效果时，优先使用真实素材。

## 字幕与话术对齐

- **OBS**：风扇片旁白几乎连续，镜头切换多落在新卖点、动作或证明开始处；护发片的图卡变化多落在产品名、等级、Pros/Cons 论点等语义节点。
- **HEU**：先做逐词转写，再按“一个可独立理解的短语”分组。镜头、关键词强调和图片插入都对齐这个语义时间轴，而不是只对齐音频波峰。
- 英语字幕优先保留自然词组与重读词；不要为了视觉等长拆开冠词与名词、介词与宾语。
- 西语通常比同义英语占用更多横向空间；优先改写为口语短句、减少同屏词数并允许更频繁换组，不要单纯缩小字号。
- 英语和西语版本应分别做断句与排版；不要只替换文本后沿用相同换行和入场时间。
- 关键词颜色只标记当前句唯一重点。连续多色会让层级失效。

### 基线字幕、升级短语与微清单

- **OBS**：`tutorial-learning-20260825-speed-pacing` 的凉鞋教程先生成全片普通字幕，再只把痛点、转折、成对 feature 和 CTA 升级成独立文字模板；模板完全覆盖某个短语时，作者删除了同时间段的普通字幕。
- **HEU**：基线字幕保证完整理解，升级层只承担当前唯一重点。若升级层已完整表达同一短语，基线字幕必须在该区间隐藏；未被升级层覆盖的共同谓语或条件仍留在基线字幕。禁止同一句在两层重复出现。
- **HEU**：自动识别必须先按语言修复语义边界，再套模板。英语保护自然词组；西语保护冠词/名词、介词短语、动词/宾语以及重音符号；不要把 ASR 段落边界当成字幕语法。
- **OBS**：同一教程在约 08:18–09:40 把“居家、快递、散步、遛弯”等并列场景只提取为名词，按发音逐项出现并保留到集合完成，共同谓语仍用普通字幕。
- **HEU**：3–4 个同级名词可做“微清单”：共享一个视觉 token，逐项累积，集合结束后统一退出。超过四项时优先删减或分页；不要把整句复制成四张大模板。

### 美妆口播：把话术角色翻译成视觉卡

- **OBS**：`tutorial-learning-20260824` 的 `asset-002`（SHA256 `76f9ab32...26f16a5`）在 1.86–17.42 秒并排展示“精剪/粗剪”。两侧底片和主要剪点基本同步；精剪侧的主要增量是持续正文字幕、单一重点色、少量语义贴图，以及结尾产品/价格段的一次强视觉转场。烧录对照不能证明精确字体、字号、动画曲线、源工程或转化效果。
- **HEU**：先标记口播角色，再选择视觉层；不要为“显得精剪”随机增加镜头。

| 口播角色 | `visual_job` | 优先视觉处理 |
|---|---|---|
| 痛点或不适 | `hook` / `problem` | 对应部位或状态特写；只强调一个痛点词 |
| 旧方案无效 | `objection` | 简短异议标签；不伪造竞品失败证据 |
| 产品名、质地 | `identity` / `feature` | 包装身份镜头 + 可见质地特写 |
| 夜间/白天用法 | `howto` | 明确区分使用状态、剂量或步骤 |
| 结果或兼容场景 | `payoff` / `proof` | 仅用真实、获授权且能支持文案的画面 |
| 价格或购买动作 | `cta` | 稳定产品英雄镜头 + 单一价格/链接动作 |

## 节奏与留存事件

每个项目创建 retention map；至少记录：

```json
{
  "start": 5.4,
  "end": 7.2,
  "spoken_idea": "The visible airflow increases after a real button press.",
  "visual_job": "proof",
  "confidence": "observed",
  "evidence_source": "asset-001 at verified source timecodes",
  "source_asset_id": "asset-001",
  "source_in": 5.4,
  "source_out": 7.2,
  "claim_ids": ["visible-airflow-change"],
  "shot_or_overlay": "Hold the real display and airflow proof in the same shot.",
  "text": "STEP IT UP",
  "text_treatment": "fine_caption; UP is the sole accent word",
  "motion": "hard cut on the button press; text pop lasts 160 ms",
  "exit_condition": "the final state is stable and readable"
}
```

- **HEU**：前 3 秒至少完成一个清晰结果、冲突或反常识问题；不要只展示包装和品牌片头。
- **HEU**：连续两个镜头若没有新增主体、动作、尺度、角度、信息或情绪，合并或删掉一个。
- **HEU**：长镜头必须有内部进展，例如数值变化、动作完成、榜单累积或观点反转。
- **HEU**：CTA 期间保留产品和购买动作的可见性；用箭头、手势或按钮强调一个目的即可。

### 节奏不是全局倍速

- **OBS**：用户直接验收认为 `Perfume_ES_FineCut_V4_FINAL_1080p30.mp4` 过快。该版本的审计记录显示 501 帧视觉母版被整体压成 410 帧，即约 `1.222x` 播放速度；这不是“小幅加快”，应作为失败反例。
- **OBS**：同一版本的最终混音 ASR 检出 39 个西语词，口播段从 0.00 延续到 13.12 秒，墙钟语速代理约 `178.4 WPM`；四个 ASR 短语合计约 11.72 秒，`speech_occupancy` 代理约 `89.3%`，三个段间空隙仅约 0.42–0.50 秒。最终混音没有再给人声做 `atempo`，所以“太快”同时暴露了合成表演本身过密和画面整体压缩两项问题。ASR 数值是该次失败的项目证据，不是西语通用上限。
- **OBS**：`tutorial-learning-20260825-speed-pacing` 的凉鞋成片展示约 30.97 秒、18 个底片镜头，平均约 1.72 秒、中位约 1.80 秒；证明动作约 1.5–2.6 秒，片尾场景枚举约 0.7–1.2 秒，CTA 约 2.5 秒。数值只描述该样本，不是固定模板。
- **INF**：可用的快节奏来自章节对比：动作证明给够完成时间，场景枚举可短，CTA 再稳定；不是把全片声音和画面统一压缩。
- **HEU**：先批准自然口播和逻辑停顿，再让画面服从声音。若超时，依次尝试删重复文案、重写短句、换更有效的镜头和缩短无信息余量；不得用全局 `setpts`/统一倍速作为时长修复。
- **HEU**：“稍快”必须作为独立 A/B 候选。对本工作区和当前用户偏好，首轮合成器控制只从自然版与约 `+3%～+5%` 候选开始；默认不生成超过 `+8%` 的候选。若用户明确要求探索更快版本，只生成预览试听，听后再次批准前不得选入或交付。任何整片统一加速都不得作为时长修复；用户要求的速度感应按具体 beat/镜头设计。逐项试听辅音、重音、情绪、句尾呼吸，并检查字幕与证据是否来得及读懂；任一项变差即退回自然版。百分比只是项目级起始控件，不是可跨模型、语言或声音复用的感知速度标准。
- **HEU**：气口分为 `artifact`（合成断裂/重复空白）、`syntax`（短语/从句）、`performance`（惊讶、犹豫、强调）和 `structure`（hook→proof、proof→CTA）。只有 `artifact` 允许批量压缩，后三类由导演意图决定。

## 音频规则

- **OBS**：参考片只有最终混音，无法可靠识别音乐名称、授权状态、独立人声响度或原始 ducking 参数。
- **OBS**：当前机械报告测得五条风扇片的整片响度约在 -17.7 至 -13.5 LUFS；true peak 约在 -1.04 至 +0.16 dBTP。它们是样本测量，不是交付标准，其中正 true peak 提示需要留出更安全的峰值余量。
- **HEU**：旁白优先，背景音乐不得掩盖辅音和产品机械声；以整片约 -16 至 -14 LUFS、true peak 不高于 -1 dBTP 作为初始检查范围，并根据素材与平台预览调整。这不是 TikTok 官方保证值。

| 触发事件 | 音效工作 | 进入点 | 禁止项 |
|---|---|---|---|
| 画面切换或产品揭示 | 短冲击、轻震动或 whoosh | 关键帧或切点 | 用长尾音效盖住下一句 |

- **HEU**：音频 QA 至少保留同一片段的前/后对听记录：只听声音能否抓住主卖点、辅音是否清楚、峰值是否安全；不得用编辑器相对 dB 数值替代整片响度和真峰值检查。

## 交付前语义 QA

1. 每个卖点能否指出对应的真实画面或授权证据？
2. 产品名、等级、bullet 和图片是否在对应词语出现时进入，而不是提前泄底或滞后？
3. 静音观看时，前 3 秒是否知道“为什么继续看”？
4. 只听声音时，逻辑是否完整且没有音乐压住旁白？
5. 任意暂停一帧，最重要信息是否仍可辨认，且没有被字幕、UI 安全区或贴图遮挡？
6. 生成素材是否可能被误认为真实产品、人物、场景、结果、实测或评价？若可能，删除、替换或在画面上明确标为说明性；明显非写实装饰仍需在规格中登记来源和边界。
7. 最终文件是否完成全时长解码、音视频流检查和代表帧目视检查？仅通过源检查或静态方案检查，不能声称已完成端到端验证。
