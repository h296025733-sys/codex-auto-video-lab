# 字幕、字体、版式与动画规范

本规范以 1080 × 1920 竖屏为制作基准。数值是由本轮 720 × 1280 参考片的可见比例归一化后形成的**制作启发式**，不是对源工程参数的精确还原，也不是 TikTok 官方安全区。

## 先说明字体识别边界

- 烧录视频只保留栅格像素，压缩、缩放、描边和抗锯齿都会改变字形。
- 可以可靠描述：无衬线/衬线、常规/粗体/斜体、字面宽窄、大小写、描边、阴影、颜色与位置。
- 不能可靠声称：“这一定是 Montserrat/Anton/某艺术字体”或“源字号就是 32 px”。除非拿到源工程、字体文件或创作者说明。
- 新项目可以使用随技能提供且许可已核验的本地字体作为**功能等价选择**，但不要写成对参考字体的鉴定结果。

## 四层文字系统

| 层级 | 作用 | 1080 × 1920 起始字号（HEU） | 字体特征 | 同屏限制 |
|---|---|---:|---|---|
| `hook` | 冲突、结果、反常识 | 80–112 px | 窄体或重粗无衬线 | 5–8 个英文词；西语尽量一条短句 |
| `caption` | 跟随口播的正文 | 54–72 px | 粗体无衬线，高可读 | 1–2 行，宽度约画面 65–72% |
| `keyword` | 当前唯一重读概念 | 跟正文同号或大 8–20% | 色彩/字重区别；偶尔斜体 | 每个短语 1 个重点 |
| `utility` | 榜单、bullet、标签、数值 | 36–48 px | 中粗无衬线 | 先保证网格和数值不拥挤 |

艺术化 accent（HEU）：68–96 px、1–3 个词，可用斜体衬线。它适合章节词、情绪词或对比词，不适合整段字幕。

### 三种保留时钟

- **OBS**：`tutorial-learning-20260825-speed-pacing` 的观点教程让章节主句跨多个口播短语稳定保留，底部字幕按短语快速更新，问号、勾叉、警示框等只在对应名词或情绪落点短暂出现。
- **HEU**：`chapter_thesis` 负责本段结论，可跨多个短语；`speech_caption` 负责逐句理解，按自然短语更新；`semantic_punctuation` 只解释当前名词、关系或情绪，短时进入并退出。三层不得重复同一句话。
- **HEU**：某个短语被 `hook`、`keyword` 或艺术模板完整替换时，同区间的 `speech_caption` 隐藏；否则观众会同时读到两份相同信息。

## 字体角色

若本技能的字体清单和许可证完整，可按下列角色使用：

- **Montserrat**：英语/西语正文字幕、bullet 和榜单标签；字面中性，语言覆盖较稳。
- **Anton**：极短 hook、数字或 CTA；仅用于少量大字，避免长西语句子。
- **DM Serif Display Italic**：1–3 个词的 editorial accent；不可替代正文字幕。

始终以 `assets/fonts/manifest.json` 记录的具体文件、提交和许可证为准。`fine_*` 预设采用 fail-closed：文件、大小、SHA-256 或许可证清单缺失时停止渲染，不静默回退系统字体，也不在运行时联网拉取。只有制作人明确批准另一种已核验字体、更新规格与权利清单并重新验证后，才能改用替代字体。

## 可读性参数

- 正文白字在复杂画面上使用约 3–5 px 深色描边，或轻阴影配半透明底；hook 可按比例增加到 5–7 px。
- 描边是为了从背景分离，不应厚到堵塞字腔。西语重音符号、`ñ`、倒问号和倒感叹号必须逐字检查。
- 全大写用于极短 hook、章节或数值。长句全大写会降低英语与西语的扫读速度。
- 一条字幕只使用一种主色和一种重点色。渐变最多两色，且只在品牌/章节 accent 中使用；默认正文不使用渐变。
- **OBS**：`tutorial-learning-20260824` 的美妆精剪对照把红色稳定用于痛点/失败/强结果词，把品牌粉用于产品名和正向利益，把白色用于说明、步骤和 CTA。它证明的是“颜色承担固定语义角色”，不是这三种颜色的通用行业标准。
- **HEU**：每个项目先定义小型语义色表，例如 `problem`、`benefit`、`instruction`、`cta`；同一角色在整片保持一致。色义必须服从品牌、对比度、市场文化和广告合规，不能只因参考片使用红/粉/白就机械照搬。
- 不用表情、箭头和闪光代替清晰的产品画面或论据。

## 版面与安全区

以下是项目内保守起点（HEU），必须用目标设备和当前 TikTok UI 复核：

- 顶部预留约 180 px，避免标题贴边。
- 底部预留约 320 px，避免文案、账号区和操作区。
- 右侧预留约 130 px，避免关键文字与产品细节落入交互按钮区。
- 字幕正文优先放在画面中下区域但高于底部预留；人物口型、眼睛、手部演示和产品显示屏优先级高于固定字幕位置。
- safe-zone 不是硬框：若主体占位冲突，移动字幕、重构镜头或短暂切换为底板，不要遮挡证据。
- **HEU**：负空间是选镜和裁切的前置条件，不只是排版后的补救。先锁定眼睛、嘴、手、产品、标签和证据动作，再确认章节主句有连续可用的负空间、底部字幕有独立轨道；不满足时换镜、重构裁切或缩短文字。

### 视觉语域

- 每个项目先声明一个主语域：`cinematic`、`editorial`、`flat-icon` 或 `meme`。字体、底板、图标、贴纸、生成插画和转场优先服从同一语域。
- 其他语域只允许作为有意且短暂的一次反差，并写明语义目的和退出点。不要在高级感香水/美妆底片中随机插入卡通 meme，也不要把电影感生成图突然塞进实拍证明段。
- 语域一致不等于风格单调：可用尺度、位置、色义、留白和运动强弱制造层级，而不是不断更换素材风格。

### Tier list / 信息板

- **OBS**：参考榜单的信息板持续占据下方约 40–45%，产品抠图随讲解进入并保留。
- **HEU**：在 1080 × 1920 中，grid 宽度约画面 72–82%，高度约 34–45%，给人物脸部和正文字幕留下上半区。
- 每格必须同时容纳产品图和等级标签；产品图保持统一视觉高度，不能因原图尺寸不同误导等级权重。
- 新产品入榜时只动画当前对象；已排名对象保持稳定，帮助观众建立空间记忆。

### Pros / Cons

- 章节标题位置固定，bullet 在说到该论点时逐条加入。
- 同一章节内已出现的 bullet 保留；章节切换时用一次清晰的颜色、标题或底板变化，而不是每条都转场。
- 一屏超过 4–5 条时，优先缩短文案或分页，不要把正文压到不可读。

## 动画语法

动画要说明“哪里变了、为什么现在变”，不能只是持续制造噪声。

| 元素 | 推荐初始参数（HEU） | 触发条件 |
|---|---|---|
| 词/短语 pop | 120–360 ms；约 100%→126%→104%→111%→100% 的单次回弹 | 原词既有钩子/痛点/反差/数字/证明/结果/CTA 语义，又有匹配的真实语音重读或停顿证据 |
| 词/短语 shake | 约 180–360 ms；短促 120% 放大并做逐步衰减的小角度左右摆动 | 全片最强且高置信的钩子、痛点或反差中断；可位于正文字幕或大号钩子内部，全片通常至多一处 |
| 产品 packshot | 发音前 0–150 ms 开始；短淡入或小位移 | 首次说出产品名/等级 |
| Bullet | 120–200 ms 淡入 + 轻微横移 | 论点开始，而非句子结束 |
| CTA 箭头 | 约 10–20 px 往返，小幅循环 | 结尾单一点击方向 |
| 章节切换 | 180–300 ms；颜色/底板/标题三者择一为主 | Pros→Cons、标准→结论 |
| 数字证明 | 数值本身连续变化，外框尽量稳定 | 画面有真实测量或设备显示 |

- **OBS**：风扇参考主要依赖硬切和镜内动作，不依赖花哨转场；箭头/手势在稳定 CTA 画面中提供持续运动。
- **OBS**：护发参考的“高级感”更多来自短语级字幕、少量 serif/italic accent、关键词颜色以及持续更新的 grid/bullet，而非每个字跳动。
- **OBS**：`tutorial-learning-20260824` 的美妆对照在约 1.90–2.67 秒先用短暂感官特效抓注意，再撤掉大面积效果并保留可读大词；普通卖点继续硬切，只在约 15.97–17.00 秒进入最终产品/价格段时使用一次强转场。具体插件、素材、曲线和商业效果无法从烧录画面确认。
- **HEU**：强钩子可分两拍：先用不遮蔽证据的短冲击建立感受，再用稳定文字和产品画面完成理解。把高能转场保留给结构换挡或最终揭示；普通卖点优先硬切或镜内动作。
- **HEU**：同一时刻只保留一个主动画焦点。人物手势、产品移动已经很强时，字幕用轻动画或静止。
- **HEU**：`!`、`?`、`?!` 或 Emoji 只作为画面表演与原句语气都支持的短时标点层；不修改转录原话，不固定成“痛点一个、结果一个”的套装，也不与正在 pulse/shake 的关键词同屏争抢。
- 出场动画通常比入场更轻；信息还需要被记住时，直接保留到下一语义节点。
- 禁止在没有实测数据时制作“增长数值”“仪表盘进度”或假评价滚动。

## 英语与西语排版

- 分别维护 `caption_en` 和 `caption_es` 的断句，不共享硬编码换行。
- 英语短语可按重读词强调；西语要保护冠词/名词、介词短语和动词宾语的自然组合。
- 西语文案变长时，按顺序处理：口语化改写 → 减少同屏词数 → 增加短语更新频率 → 最后才小幅缩字号。
- 西语使用的字体必须覆盖 `á é í ó ú ü ñ ¿ ¡`；渲染前做字符缺失检查。
- 口播快不等于字幕要逐字闪烁。每个短语至少应覆盖其实际发音区间，并给用户足够时间扫读。
- 自动字幕断句必须在人审语义后再进入排版。不得拆开英语的介词/宾语或西语的冠词/名词、介词短语、动词/宾语；升级大字不能以破坏自然语块来换取视觉对称。

## 视觉 QA

1. 在 100%、50% 和手机宽度预览正文、重音符号、数字和 CTA。
2. 抽查每种背景亮度；文字不能只在暗帧可读。
3. 检查字幕是否遮挡脸、嘴、手、产品名称、接口、显示屏或实测结果。
4. 检查 packshot 是否恰好对应当前产品，且没有提前显示答案。
5. 逐帧检查短动画首尾是否跳变、被裁切或闪黑。
6. 导出后再检查烧录字体；编辑器预览正确不等于编码结果正确。
